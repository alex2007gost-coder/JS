# Введение в JavaScript

JavaScript — это язык программирования, который делает веб-страницы интерактивными. Вместе с HTML и CSS он является одной из основных технологий всемирной паутины.

## Переменные

Для объявления переменных в JavaScript используются ключевые слова `var`, `let` и `const`:

```javascript
let name = "Иван";
const age = 25;
var oldWay = "устаревший способ";
